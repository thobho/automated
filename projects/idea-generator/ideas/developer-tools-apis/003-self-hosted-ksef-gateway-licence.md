# 003 — Self-hosted KSeF gateway (annual licence)
**One-liner:** A Docker image with a plain REST API in front of KSeF 2.0 (sessions, certificates/tokens, send queue, duplicate guard, purchase-invoice mirror with package export, webhooks), licensed per year to ERP vendors and in-house IT teams that do not want to host or build KSeF plumbing.
**Field:** developer-tools-apis | **Type:** library (self-hosted software, API)
**Target customer:** Small and mid-size Polish ERP/e-commerce/billing software vendors and companies with their own IT (CTO or lead developer), plus integrators. Count: unverified. Context: about 1.75 million active VAT payers must use KSeF (L5-F03, official-data based); no count of software vendors found.
**Problem:** The official API is free but demanding: rate limits per (taxpayer context, IP) of e.g. 20 requests per hour for invoice-metadata/package export, so a product must keep a local mirror and use package export (limits doc dated 14.09.2026, L7-F03); duplicates after outages (issue "Awaria KSeF? masowe duplikaty", 72 comments), no change notifications (ministry consultation thread, 103 comments), and token/certificate handling disputes (73 comments) (L6-F06).
**MVP scope (≤6 weeks):** (1) Java or Node service, Docker image, Postgres/SQLite. (2) Auth: certificate and token management per client context, encrypted at rest. (3) `POST /invoices` with idempotency key, retry and dedup queue, UPO retrieval. (4) Incremental purchase-invoice sync via package export into the local mirror, `GET /invoices?since=` and webhooks. (5) FA(3) validation before sending. (6) Licence-key check (offline-capable), admin UI minimal. Tests: official TEST/DEMO environments, free to use, data shared between integrators (L7-F02). Not in MVP: PDF rendering, OCR, bookkeeping.
**Why now:** KSeF is mandatory in three waves (1 Feb 2026, 1 Apr 2026, 1 Jan 2027) (official stage page); the ministry froze the API contract from 22 Dec 2025 and moved environment hostnames (old ones off 17 Jan 2026), so the integration surface is now stable enough to productise (podatki.biz summaries of ministry announcements).
**Foreign analogues:** EmailEngine (Estonia): self-hosted email API licensed 1,450 USD/year, 237 active subscriptions, 19,419–19,422 USD MRR, 616k USD all-time, one-person, Stripe-verified, SEO main channel (TrustMRR, accessed 2026-10-29). Different domain, same model. B2Brouter offers a white-label KSeF API to software vendors with an ISO 27001 badge and a startup programme at 100% discount (its own page; country of origin and size not verified).
**Competition (PL / global):** Free: official clients in C# and Java (115 and 49 stars), community clients in Python (82 and 29 stars), PHP (92), Go, TypeScript, and at least 700 matching GitHub repos (L2-F10, L6-F17, L7-F22). Commercial: B2Brouter (hosted, no public price, startup programme free), Crido Compass KSeF API connector (self-hosted REST for companies with in-house IT, no public price; the page returned 403 to my fetch, details from a search summary), Sii Poland Dynamics 365 module, Innowise custom connector work (quote only). ERP vendors with built-in KSeF (Comarch Optima, Symfonia) cover their own customers. Gap: a transparent, public-price, small-vendor package; but no public price anywhere, so the price gap cannot be proven.
**Evidence of pain:** CIRFMF/ksef-api: 824 issues, 120 open; #565 token rollback (73 comments, quote: "biura księgowe wymagają od przedsiębiorców tego certyfikatu tylko po to, żeby móc w jego imieniu wysyłać i odbierać faktury"), #794 event model consultation (103 comments), #786 duplicates after outage (72 comments) (L6-F06). Rate-limit complaints are inferred from the limit design, not quoted. Ministry accepts requests for individual higher limits via a form with a justification document (ksef.podatki.gov.pl), a sign that default limits bind real integrators. Counter: the pain comes from developers who may build in-house; the ministry may add an event model and relax limits. Trend data not checked: unverified.
**Monetization:** Annual licence per organisation or per taxpayer-context pack, 1,500–6,000 PLN/year, tiers by number of client contexts (estimate; EmailEngine's 1,450 USD per year is about 5,800 PLN at 4 PLN/USD, my assumption). Payer: the vendor's CTO/owner.
**Revenue sketch (estimate):** Assumes an average licence of 4,000 PLN/year (333 PLN/month). 6 months: 6 licences = about 2,000 PLN MRR. 12 months: 15 licences = about 5,000 PLN MRR. 10,000 PLN MRR needs about 30 licences, EmailEngine shows 237 licences globally; the Polish vendor market is much smaller (estimate).
**First 10 customers:** Answer threads in CIRFMF/ksef-api issues and Polish dev communities with code, publish a free tier (1 taxpayer context) on GitHub, list on Docker Hub, SEO for "KSeF brama API", direct outreach to small vendors that advertise "integracja z KSeF w przygotowaniu" on their sites (listable via Google).
**Build complexity:** medium. Risks: certificate/token secrets custody and security duty, correctness under outage and duplicate conditions (hard to test at production scale, L7-F03), spec drift (frozen contract reduces this), support load from developers.
**Pros / Cons / Risks:** Pros: B2B annual licence, no hosting for the vendor, public API without approval, a verified analogue earning above target. Cons: crowded free OSS (1,250+ KSeF repos per the shortlist; GitHub API shows 709 matching repos created in 2025), developers prefer to build in-house, tiny vendor audience, ministry may fix gaps. Risks: liability for lost/duplicated invoices, platform dependency on the ministry, KSeF token sunset at end of 2026 (unverified secondary source).
**Scores (1–5):** L1 1, L2 2, L3 3, L4 4, L5 3, L6 4, L7 4, L8 3, L9 3 | **Weighted:** 3.1 / 5 | **Chance band:** 5–15% (T16 review: L5 4→3, see Review changes; write-up value was 3.2; L4 rests on one verified analogue, so 4 not 5)
**Cheapest validation test (≤1 week, ≤200 PLN):** Publish a README plus a 3-minute screencast of the gateway design and a "Licence 3,000 PLN/year, pilot free" page; post in the ksef-api issues where relevant and in Polish dev groups; email 30 small ERP/e-shop software vendors. Success: 5 replies asking for a pilot and 2 accepting a stated price.
**Kill criteria:** Fewer than 3 of 30 vendors say they would use a gateway rather than the official client; or the ministry ships an event/webhook model plus higher default limits; or two vendors report they already license a comparable gateway at a price under 1,000 PLN/year.
**Confidence:** low
**Devil's advocate:** The buyer is a developer, and developers build. Every Polish vendor that had to issue invoices through KSeF faced the 1 Feb / 1 Apr 2026 deadlines; by today (29 Oct 2026) they have shipped something, mostly on the free official Java/C# clients or one of 700+ GitHub libraries. A gateway sold now competes with sunk cost, not with a blank page: the vendor must rip out working code to buy a licence. The remaining dated triggers are smaller: the 1 Jan 2027 wave (only the smallest taxpayers, so it matters mainly to micro-firm invoicing tools) and the end-of-2026 token sunset that forces certificate handling (secondary source, unverified). The pain in the GitHub issues is with the ministry's design choices (tokens, missing event model, duplicates after outages); the ministry can fix the event model and already grants higher limits on request, which would erase two of the five MVP features. EmailEngine proves the self-hosted licence model, but it sells to a global market of developers; the Polish KSeF vendor market is one country and its size is still unsourced, so 30 licences (the 10,000 PLN MRR line) cannot be checked against the 20× rule. Liability is asymmetric: a lost or duplicated invoice in a customer's ERP is blamed on the gateway. Second search found no new direct rival with a public price (B2Brouter still quote/startup-free; a Docker Hub image "cered/ksef-api" with ~951 pulls and no description, [hub.docker.com](https://hub.docker.com/r/cered/ksef-api), purpose unverified), and one adjacent price signal that supports L3: Streamsoft's "ala KSeF Mini", a standalone KSeF module exporting to other accounting programs, sells from 1,900 PLN setup plus 120 PLN/month net (reseller page, Q2 2026 price list, [kluczesoft.pl](https://kluczesoft.pl/wiedza/licencje/streamsoft-ala-ksef)), so companies do pay recurring fees for KSeF plumbing.
**Review changes:** L5 4→3: the binding deadlines for almost all payers passed in Feb/Apr 2026, so the trigger now pushes few new buyers (1 Jan 2027 wave and token sunset remain); weighted 3.2→3.1, band stays 5–15% (lower end). Other scores hold: L3 3 now has a second price signal (Streamsoft Mini 120 PLN/month + setup); L6 4 rests on three 70–100-comment integrator threads, which are the target buyers. Validation should ask vendors what they already built, not whether they need KSeF.
