# Poland check, batch B (T17)

Gap verdicts for the 23 batch-B themes (ranks 24–46) of [THEMES.md](../../themes/THEMES.md). Sources accessed **2026-11-04** unless a file says otherwise. Summary table at the end.

## Method
Same as [batch A](../A/README.md#method):
- **Leaders tried** without creating accounts: public site, pricing page, language switcher, help centre, docs and signup page read via web fetch and search (English and Polish). Nothing was signed up for, paid, or submitted. What could not be checked is listed in each file.
- **Google autocomplete** (Polish): queries sent to Google's public suggestion endpoint (`suggestqueries.google.com/complete/search?client=firefox&hl=pl&gl=pl`) on 2026-11-04; the suggestions returned are quoted. Empty suggestions are read as low search volume. Google Trends, Keyword Planner, Wykop and Facebook groups need JavaScript or a login and were **not** checked; job-board and press searches were done with web search.
- **Moat IDs** (M01…) refer to [local-moats.md](../../research/poland/local-moats.md); **D/DD IDs** to [demography.md](../../research/poland/demography.md); CEE check uses the [R6 README](../../research/regions/R6-cee-peers/README.md) and [R6 catalogue](../../catalogue/R6-cee-peers.csv).
- **Verdicts:** *open gap* = no Polish product and the Western leader does not serve Poland; *partial* = Polish or Western products exist but miss a definable Polish segment or workflow; *taken* = a Polish-adapted product already covers the core workflow at a price a solo founder cannot beat.
