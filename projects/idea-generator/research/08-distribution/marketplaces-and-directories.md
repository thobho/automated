# Lens 8 — Marketplaces, app stores and integrator directories

Part of [lens 8](README.md). All sources accessed 2026-10-29. Reliability notes: pages were read via a summarising fetch tool, so quotes are as returned; "unverified" marks what I could not confirm on a primary page.

## L8-F01 — Allegro has a "Certyfikowany Integrator" programme, not an app store
Allegro Developer announced (18 March 2025) a programme for applications that use the Allegro API and "zapewniają wysoką jakość i rzetelność usług". Benefits: listing on a dedicated Allegro partner page, a badge for the integrator's own site, direct contact with the Allegro API support team, invitations to API partner meetings and webinars. Applications go by e-mail to a submissions address; eligibility criteria sit in separate regulations (not read) and the announcement mentions no fee. Source: https://developer.allegro.pl/news/uruchomilismy-program-certyfikowany-integrator-allegro-3A2Gg8b3LhY (accessed 2026-10-29). Implication: the only Allegro-run discovery surface for third-party tools is a curated list for integrators; a small seller tool is found through its own SEO and channels, not through Allegro.

## L8-F02 — That list holds 12 apps and they are the incumbents
The Certified Integrators page lists 12: ten "Global Partners" (SellRocket, Comarch e-Sale, xSale, Niezbędnik Sprzedawcy, Sky-Shop, BaseLinker, Omnicado, Apilo, IdoSell, IDEA Commerce) and two "Local Partners" for allegro.pl only (Sello NX, EasyUploader). Source: https://www.allegro.com/partners/certified-integrators (accessed 2026-10-29). Implication: a new "Allegro + X" multichannel tool meets all of these; a narrow add-on that sits next to one of them (e.g. on BaseLinker's API, see [L7-F16](../07-founder-fit/costs-and-ops.md)) does not need certification to exist.

## L8-F03 — Shopify App Store: ranking is partly install- and review-driven; "Built for Shopify" boosts discovery
Shopify's docs say Built for Shopify (BFS) apps get a badge, a search filter, higher App Store search ranking, possible placement in the first collection on the home and category pages, the in-admin "Picked for you" modal, and a prioritised review queue for later apps; BFS requires a minimum number of installs, reviews and a minimum rating (numbers on a separate page, not read). Source: https://shopify.dev/docs/apps/launch/built-for-shopify (accessed 2026-10-29). A Shopify staff reply in the developer community lists category placement factors: description, total installs and uninstalls, use of Billing APIs, search terms, reviews; the algorithm is not public. Source: https://community.shopify.com/t/need-help-abnormal-keyword-rank-on-shopify-app-store/61797 (via search summary, accessed 2026-10-29; unverified on the page itself). Fees and review times are in [L7-F05, F15](../07-founder-fit/api-access.md). Implication: a new Shopify app starts with zero installs and zero reviews, so the first 100 installs must come from outside the store (outreach, content) or from low-competition search terms inside it.

## L8-F04 — WordPress.org: free listing, but a strict freemium rule
Guidelines allow a plugin to be the interface to a paid third-party service if the service has "substantial functionality" and is documented in the readme; they forbid locking features behind payment or quotas in the directory version, licence-key-only services, and storefront-only plugins; "Powered by" links must be optional and off by default; upgrade prompts must be limited and dismissible. Premium code is to be sold as an external service or an add-on hosted outside WordPress.org. Source: https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/ (accessed 2026-10-29). Review time: see [L7-F08](../07-founder-fit/api-access.md). Implication: the viable model is "free plugin as the front door + SaaS behind it", where the SaaS does real work (e.g. OCR, scanning, e-invoice conversion).

## L8-F05 — Atlassian Marketplace: 0% fee on Forge until USD 1M, then ~17%
Atlassian's developer-community announcement: from 1 January 2026, partners pay 0% on eligible Forge revenue until lifetime Forge revenue reaches USD 1 million (app must use only Forge modules, auth and UI); standard Forge share 16%, rising to 17% on 1 July 2026; Connect apps 20%, rising to 25% on 1 July 2026. Source: https://community.developer.atlassian.com/t/marketplace-revenue-share-updates-2026/91727 (accessed 2026-10-29). Atlassian's developer page says the Marketplace has "6,000+ apps", 2,000+ vendors and USD 6B lifetime sales (vendor-reported marketing figure): https://developer.atlassian.com/platform/marketplace/ (accessed 2026-10-29). A search summary gave different dates (October 2026) for the same step, so check the thread before relying on the 1 July / 1 October date. Implication: the cheapest commission anywhere in this lens for a solo developer; the audience is Jira/Confluence admins in companies (B2B, English, a "Polish moat" does not apply).

## L8-F06 — DATEV-Marktplatz: the German accountant channel, gated by a DATEV Online API integration
Vendors pass an admission process: positioning towards DATEV members, calls with the vendor's reference customers, a check of the company's finances, relevance as a complement to DATEV's portfolio, and integration of a DATEV data service (Online API; vendors with only a desktop API or file interface are not listed). Fees: "Premium Partner" pay a revenue-based fee for referrals; "Schnittstellen Partner" pay a monthly base fee plus a per-click price (amounts not published). The marketplace had 2,133 average monthly active users over the six months to 1 July 2026 (DATEV's figure). Premium Partners need an information-security certificate from 30 June 2026. Source: https://www.datev.de/web/de/ueber-datev/das-digitale-oekosystem-von-datev/partnering/datev-marktplatz/faq-zum-datev-marktplatz/ (accessed 2026-10-29). Implication: reaching German Steuerberater via DATEV needs reference customers first, so it is a month-6+ channel, not a first-100 channel. The 2,133 MAU figure also shows how small the audience is. Relevant to the German E-Rechnung seeds of lenses 1, 2, 5.

## L8-F07 — Chrome Web Store: one-time developer fee, amount not on the current official page
Official docs say a developer must "pay a one-time registration fee" and do not state the amount. The USD 5 figure comes from 2010 launch coverage and third-party guides (unverified for 2026). Sources: https://developer.chrome.com/docs/webstore/register?hl=nl and https://www.computerworld.com/article/1554628/google-makes-chrome-devs-dig-into-pockets.html (accessed 2026-10-29). Review rules: [L7-F07](../07-founder-fit/api-access.md). Implication: negligible cost; discovery is by store search, so low-competition utility extensions can get organic installs, but monetisation is a separate problem (lens 3).
