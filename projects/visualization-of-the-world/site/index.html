What the library can do

A proof-of-concept for the Polska w danych visualisations: Apache ECharts 6.1.0 in the project design system, on real Polish boundaries, with clearly labelled synthetic numbers. It is the reference for how every later chart should look and behave.

Chart catalogue

Line, area, stacked and grouped bars, scatter, bubble, heatmap, treemap, sunburst, small multiples, slope, bump and indexed series.

Motion and interaction

Timeline playback, place-type filter, brushing with linked views, zoom and pan, animated shape changes.

Maps

Voivodeship choropleth, drill-down to powiats, city bubbles, zoom to a region, touch.

Formats

CSV, JSON, GeoJSON and TopoJSON in; PNG, SVG and CSV out.

Layout and polish

375 px to desktop, light and dark, loading, empty and error states, the Source footer.

Capabilities matrix

Every capability with status, code location and docs link, including what is not possible.
