Layout and polish

Responsive from 375 px to desktop, light and dark, and the three states every data view needs: loading, empty, error. The Source footer is a component used under every chart.

Responsive

Resize the window: columns go 4 to 8 to 12 at 600 and 960 px, the top bar becomes a menu below 960 px, charts re-flow (small multiples go from 4 to 3 columns, labels rotate).

Light and dark

The Theme switch in the top bar (Menu on phones) sets light, dark or follows the system. Charts read their colours from the same tokens, so they redraw with the page. Data colours stay the same in both themes except the map ramp, which flips.

Source footer component

Created by Votw.figure(), which throws when a spec has no source. Markup: footer.chart-source > span.chart-source__label + a + span.chart-source__meta. scripts/verify_site.cjs fails if any chart card on any page lacks it.
